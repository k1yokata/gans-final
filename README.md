# GAN-Based Synthetic Data Generation for Public Procurement Risk Detection

## Project Topic

This project focuses on using Generative Adversarial Networks (GANs) to generate synthetic public procurement data for corruption risk analysis.

## Research Connection

The project is connected with the dissertation topic:

**Machine Learning Based Early Warning for Corruption Risk in Public Procurement**

The main idea is to use GAN-generated synthetic procurement records to support risk detection, improve data availability, and demonstrate how generative models can be applied in public procurement analytics.

## Main Goal

To develop a GAN-based prototype that can learn patterns from real procurement data and generate synthetic procurement records that resemble real tenders.

## Project Tasks

1. Collect and prepare public procurement data.
2. Clean and preprocess tabular procurement records.
3. Select key risk-related features.
4. Design a GAN model for tabular data generation.
5. Train the GAN model in Google Colab.
6. Generate synthetic procurement records.
7. Compare real and synthetic data distributions.
8. Explain how the model supports corruption risk detection.
